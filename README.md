# Towlab Hotel & Suites — Website Redesign

A premium website redesign concept for Towlab Hotel & Suites,
Akure, Ondo State.

## Live Demo

[View Live Website](YOUR-GITHUB-PAGES-LINK)

## Overview

This project explores how Towlab Hotel & Suites could present
its hospitality experience through a more modern, premium,
conversion-focused website.

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Features

- Responsive design
- Premium hospitality UI
- Room showcase
- Booking enquiry interface
- Guest reviews section
- Amenities section
- Gallery
- Contact section
- Google Maps integration
- Mobile navigation
- Scroll animations

## Disclaimer

This is an independent redesign concept created for
portfolio and demonstration purposes. It is not the
official website of Towlab Hotel & Suites.
